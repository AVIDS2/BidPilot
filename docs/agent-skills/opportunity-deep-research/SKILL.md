# 招标机会深度调研

## 目标

把公开招标检索收敛为可决策的候选清单，而不是持续搜索。只读调研不得创建项目、下载附件、导入资料、提交表单或启动工作流。

## 用户沟通

开始工具调用前，用一句话说明本轮会核对的范围、来源和截止时间。每完成一个阶段，给出一句有事实含量的进度，例如“已找到常州市级与区级官方公告，正在核对仍可报名的项目”，不要汇报搜索数量、工具名或内部预算。

## 阶段

1. **界定范围**：提取地域、行业、能力、时间状态、数量上限和禁止动作。缺少决定性条件时只问一个问题；可以合理默认时直接继续。
2. **发现候选**：第一波最多并行 3 个互补检索，分别覆盖政府采购、公共资源交易和采购人/主管部门官方来源。不同检索必须解决不同信息缺口，禁止同义改写后重复搜索。
3. **核验候选**：优先公告原文。核对项目名称、采购人、预算、报名/投标截止时间、当前状态、资格要求和原文链接。搜索摘要不足以证明的字段标记“待核实”，不得猜测。
4. **补缺搜索**：只有候选仍缺少会改变决策的关键字段时，允许第二波最多 2 个定向检索。连续两次没有新增官方来源，或累计 6 次联网搜索后，必须停止检索并进入综合。
5. **综合输出**：去重后输出不超过用户要求的数量。每条说明匹配理由、明确要求、风险和待确认信息。最后只提出用户要求的下一步问题。

## 收敛规则

- 相同标准化检索式只执行一次。
- 同一公告的转载、聚合页和搜索结果页只保留官方原文。
- 已有足够候选时不得为了“更全面”继续搜索。
- 达到检索预算、没有新增官方来源、或关键截止时间无法从公开来源确认时，必须结束并诚实标记未知。
- 只读范围内发现附件时只说明存在，不调用下载或入库工具。

## 输出检查

- 候选数量不超过上限。
- 每条都有可点击原文链接和来源平台。
- 截止时间与当前状态有证据；否则写“待核实”。
- 资格、业绩、人员、本地化要求不凭常识补全。
- 不展示搜索次数、内部工具参数、“已完成”等空状态。
