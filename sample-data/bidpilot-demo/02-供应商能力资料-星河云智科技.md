# 星河云智科技有限公司能力资料（演示）

## 一、公司简介

星河云智科技有限公司是一家面向政府与园区场景的软件平台服务商，专注于城市治理、智慧社区、工单协同、数据治理和 AI 辅助决策系统建设。

公司成立于 2018 年，核心团队来自政务信息化、数据平台和人工智能工程领域。公司现有研发人员 86 人，其中后端工程师 24 人、前端工程师 18 人、算法工程师 12 人、测试工程师 10 人、项目实施与运维人员 22 人。

## 二、核心能力

### 2.1 社区治理平台能力

公司已形成事件上报、工单派发、网格协同、移动巡检、居民评价、数据看板和运维监管一体化能力。

系统支持多组织、多社区、多角色权限模型，可根据街道、社区、小区、网格进行权限隔离和数据汇总。

### 2.2 AI 辅助治理能力

公司建设了面向社区事件的文本分类、智能摘要、风险识别、处理建议推荐和报表自动生成能力。

AI 能力支持私有化部署和第三方大模型 API 接入。系统在调用大模型时会进行脱敏处理，并保留调用日志用于审计。

### 2.3 数据安全能力

公司平台支持以下安全机制：

- RBAC 角色权限控制。
- 操作日志与审计追踪。
- 敏感字段加密存储。
- API 访问限流。
- 登录验证码与异常登录检测。
- 数据备份与恢复。

### 2.4 国产化适配

平台已完成以下环境适配测试：

- 统信 UOS 服务器版。
- 麒麟操作系统。
- PostgreSQL 14。
- 达梦数据库兼容模式。
- Docker 与 Docker Compose 容器化部署。

## 三、产品架构

平台采用前后端分离架构：

- Web 前端：React + TypeScript。
- 后端服务：Python FastAPI 与 Java Spring Boot 混合架构。
- 数据库：PostgreSQL / 达梦。
- 缓存与队列：Redis。
- 对象存储：MinIO / S3 兼容对象存储。
- AI 服务：支持 OpenAI 协议、Anthropic Messages 协议和本地模型网关。

## 四、项目团队配置

本项目拟投入团队 12 人：

- 项目经理 1 人，负责项目计划、沟通协调和风险控制。
- 产品经理 1 人，负责需求调研、原型确认和验收口径。
- 架构师 1 人，负责总体架构和技术把关。
- 后端工程师 3 人，负责业务服务、权限、接口和数据模型。
- 前端工程师 2 人，负责工作台、移动端和可视化看板。
- 算法工程师 1 人，负责 AI 分类、摘要和知识检索能力。
- 测试工程师 1 人，负责功能测试、接口测试和回归测试。
- 实施运维工程师 2 人，负责部署、培训和上线保障。

## 五、服务承诺

公司承诺提供 3 年免费质保服务。质保期内提供 7x12 小时远程支持，重大故障 2 小时内响应，8 小时内提供解决方案。

系统上线后提供不少于 5 次巡检服务，每季度提交一次运行报告。

## 六、资质与认证

公司具备以下资质：

- ISO 9001 质量管理体系认证。
- ISO 27001 信息安全管理体系认证。
- CMMI 3 软件能力成熟度认证。
- 软件企业证书。
- 多项软件著作权。
